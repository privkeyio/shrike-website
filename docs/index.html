From Sparrow's documentation #

Most of the wallet is upstream's work and behaves as it does there, so rather than restate it, Sparrow's documentation is worth reading alongside these pages. It covers wallet creation, hardware wallets, the transaction editor, airgapped workflows, privacy and server performance.

Two differences run through all of it, so keep them in mind wherever you are reading:

  • Shrike offers no public servers. Anywhere upstream assumes you can pick one, that option does not exist here. Your own node, or your own Electrum server in front of it, is the only arrangement. See connecting a node.
  • Signing has to opt in. A device on stock firmware still signs, but produces signatures that can be replayed. See replay protection and hardware wallet firmware.
